# Runie для Raycast

Спросить Руни и найти то, что он проиндексировал у вас на Mac, — не открывая его чат.

| Команда | Что делает |
| --- | --- |
| **Спросить Руни** | Открывает чат у орба и сразу задаёт вопрос. |
| **Найти у себя** | Поиск по указателю Руни: файлы, письма, заметки, переписка, история браузера. Файл открывается, страница — в браузере, про остальное можно спросить Руни. |
| **Открыть чат Руни** | Просто открыть чат. |
| **Новый разговор** | Начать с чистого листа. |

Поиск в Raycast идёт по словам — прямо по базе указателя, только на чтение. Искать по смыслу умеет сам Руни: если по словам не нашлось, в списке есть «Спросить Руни».

Команды приходят к Руни ссылкой `runie://`. Вопрос из Raycast Руни отправляет сразу; ссылку от любого другого приложения — только подставляет в поле, чтобы сайт не мог говорить от вашего имени.

## Установка

```bash
cd Integrations/raycast
npm install
npm run dev
```

Нужен установленный Runie.
