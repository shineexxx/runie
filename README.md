# Runie

**Ассистент для Mac, который расширяется markdown-файлом.**

Runie — нативное macOS-приложение, дающее человеческий интерфейс агенту, который у вас
уже есть. Весь интеллект берётся из установленного Claude Code CLI и вашей подписки.
Своей модели, своего облака, своего аккаунта у Runie нет.

Способности Runie — не код внутри приложения, а файлы на диске: `~/.claude/skills` и
конфигурация MCP. Поэтому **любой навык и любой MCP-сервер, написанный для Claude Code
где угодно, работает в Runie в день написания.** Новая способность — это markdown-файл,
а не pull request, сборка и релиз.

> Статус: ранняя разработка. Пока здесь только каркас.

## Что это не

- Не IDE и не замена Claude Code для разработчиков.
- Не своя модель и не обёртка над API.
- Не продукт с подпиской. Деньги вы платите Anthropic, а не нам.

## Требования

- macOS 15 или новее
- Установленный Claude Code и выполненный `claude login`

## Принципы

- Открытый код, лицензия MIT.
- Runie никогда не трогает OAuth-токены и не ходит в API напрямую — только через процесс `claude`.
- Ноль телеметрии, ноль аккаунтов, ноль серверов проекта.
- Ничего необратимого без явного подтверждения человека.
- Никаких фоновых запусков по таймеру: проактивность строится на событиях присутствия.

## Структура

```
App/Runie/            приложение (SwiftUI)
Packages/RunieKit/    вся логика, тестируется без UI
scripts/              сборка и упаковка
```

Логика живёт в `RunieKit` и не зависит от UI. Всё, что специфично для Claude Code —
имена флагов, форма JSON, продолжение сессий — изолировано в одном адаптере, чтобы
изменения в CLI не ломали приложение целиком.

## Сборка

```bash
xcodebuild -project Runie.xcodeproj -scheme Runie -configuration Debug build
```

Тесты логики без Xcode:

```bash
swift test --package-path Packages/RunieKit
```

## Разрешения

Runie просит доступ к Accessibility и Automation, чтобы управлять приложениями от вашего
имени. Каждое действие, которое нельзя откатить, требует подтверждения в отдельном окне.
Полный список разрешений и зачем каждое нужно появится здесь до первого релиза.
