# Runie — открытый ассистент для Mac поверх Claude Code

## Идея в одном абзаце

Runie — нативный macOS-ассистент в духе Eney от MacPaw: плавающее окно с чатом, голосовой ввод, умение работать с файлами, почтой, календарём и приложениями Mac. Но с открытым кодом и без своей облачной модели. Весь интеллект берётся из Claude Code CLI, который пользователь уже оплачивает подпиской Claude Pro или Max. Runie — это только оболочка и набор навыков для Mac. Пользователь получает ассистента уровня Eney, которого он полностью контролирует и за которого не платит второй раз.

## Имя

Runie — маленькая руна: знак, который делает. Читается «Руни», одинаково по-русски и по-английски, звучит как имя персонажа, а не как утилита. Голосовая команда «Руни, найди файл» произносится естественно. Имя свободно: нет продуктов, приложений и репозиториев с таким названием. Лого с руной и лендинг уже есть — они переезжают из прежнего проекта Rune с заменой одного слова.

## Почему сейчас

Eney показал, что людям нужен не чат, а ассистент, который делает задачи на компьютере. Но Eney закрытый, платный по кредитам и работает на неназванных облачных моделях. С другой стороны, Claude Code уже умеет всё, что нужно агенту: многошаговые задачи, инструменты, MCP, разрешения, память сессий, skills — и всё это доступно по обычной подписке. Не хватает одного: человеческого интерфейса для не-программиста. Все существующие GUI-обёртки над Claude Code (Clarc, claude-mac, claude-desktop) сделаны как IDE-панели для кодинга. Ниша «личный ассистент для Mac поверх своей подписки» пуста.

## Что видит пользователь

Иконка в menubar и глобальный хоткей. По нажатию появляется компактное окно: поле ввода, кнопка микрофона, история последних задач. Пользователь говорит или пишет: «сожми вчерашние скриншоты и отправь Саше», «что у меня по календарю, сделай список дел», «найди в Notion смету и обнови сроки». Runie показывает ход работы — какие инструменты вызывает, что читает, что меняет — и просит подтверждения перед действиями, которые нельзя откатить. Результат остаётся в истории, к нему можно вернуться и продолжить.

Никакой настройки на старте: если на Mac установлен Claude Code и выполнен `claude login`, Runie работает сразу.

## Как это устроено

Runie написан на Swift и SwiftUI, без Electron. Он запускает настоящий процесс `claude` в headless-режиме (`claude -p --output-format stream-json --input-format stream-json`), пишет сообщения пользователя в stdin и читает поток событий из stdout: текст, вызовы инструментов, результаты, запросы разрешений. Эти события рендерятся в нативном интерфейсе. Продолжение диалога — через `--resume`, история хранится там, где её уже хранит Claude Code, своя база не нужна.

Способности Runie на Mac — это MCP-серверы и skills, которые приложение подключает к Claude Code. Часть готовые: управление Calendar, Mail, Notes, Reminders и iMessage через AppleScript; управление любыми приложениями через Accessibility без захвата мыши. Часть свои — Swift MCP-сервер под типовые задачи: файлы, изображения, PDF, буфер обмена, скриншоты. Пользователь включает и выключает навыки из настроек, а продвинутый — добавляет свои в `~/.claude/skills`.

Проактивность — отличительная черта Eney — реализуется через фоновые запуски `claude` по расписанию и Claude Code hooks: утренняя сводка, напоминание о задачах, подготовка к встрече из календаря.

## Принципы

Открытый код и лицензия MIT. Runie никогда не трогает OAuth-токены и не ходит в API напрямую — только через процесс `claude`, так что использование подписки остаётся в рамках правил Anthropic. Никакой телеметрии, никаких аккаунтов, никаких серверов проекта. Всё, что может выполниться локально, выполняется локально. Парсер формата CLI изолирован в одном модуле, чтобы изменения в Claude Code не ломали всё приложение.

## Дорожная карта

Первая версия — окно с чатом, стриминг ответа, продолжение сессий. Ей уже можно пользоваться. Вторая — отображение инструментов, подтверждения с diff, вложения файлов и картинок, хоткей и menubar. Третья — голосовой ввод, каталог навыков с включением из интерфейса, набор Mac-MCP. Четвёртая — проактивные сценарии и автоматизации по расписанию. Дальше — сообщество: навыки как плагины, шаблоны сценариев, поддержка других CLI-агентов при желании.

## Чем Runie не является

Это не IDE и не замена Claude Code для разработчиков. Это не своя модель и не обёртка над API. Это не продукт с подпиской — деньги пользователь платит Anthropic, а не нам. В названии и материалах нет слова «Claude».

## Кому это нужно

Тем, у кого уже есть подписка Claude и Mac, кто хочет ассистента для повседневных задач, а не чат в браузере. Разработчикам, которые хотят собрать своего ассистента, не переписывая агентскую часть. И тем, кто не готов отдавать содержимое своего Mac закрытому облаку за кредиты.
